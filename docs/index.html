From a three-hour stream to a Short you can trust.

Clip Studio watches live streams with a rolling buffer, plans a real edit around the payoff, renders 1080×1920 video with Hindi or English captions, and checks quality before anything reaches your output folder. It never uploads or publishes unless you do it yourself.

Plans the editA model reads the timestamped transcript and picks setup, payoff and reaction, with quotes checked against what was actually said.
Honest scoresHook, clarity and payoff are gated separately. High energy cannot rescue a clip with no ending.
Safe framingContext, gameplay and gameplay + facecam presets keep captions out of the phone UI.
Fails safeNo transcript or a model error means a clip goes to review, never silently approved.

Run it

Three commands.

Clone and install

git clone https://github.com/gaur-adi/clip-studio.git && cd clip-studio
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

Point it at your Ollama host

echo "http://YOUR-LLM-HOST:11434" > ollama_host.txt
echo "gemma4:12b" > ollama_model.txt

Start the local app

./run_app.sh   # http://127.0.0.1:8765, local only
